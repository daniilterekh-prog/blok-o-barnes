# Версии с кнопкой «Читать далее»

В этой папке лежат две самостоятельные версии блока «О BARNES»:

- `desktop/index.html` — desktop-версия;
- `mobile/index.html` — mobile-версия.

В обеих версиях основной текст скрыт до нажатия на кнопку «Читать далее». После нажатия раскрывается полный текст, а подпись кнопки меняется на «Свернуть».
