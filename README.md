# Блок о BARNES

Самостоятельный HTML-блок «Элитная недвижимость как часть вашей жизни и капитала» для BARNES Moscow.

Внутри:

- адаптивная сетка из трёх карточек;
- локальные изображения для услуг BARNES;
- крупные названия карточек и ссылка «Узнать подробнее»;
- локальные шрифты Tilda Sans без внешних зависимостей.

## Просмотр

Откройте `index.html` в браузере или разместите содержимое репозитория на GitHub Pages.

Отдельные версии с видимой кнопкой «Читать далее»:

- [Desktop-версия](read-more/desktop/)
- [Mobile-версия](read-more/mobile/)
